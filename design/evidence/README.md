# Evidence

These documents preserve the external evidence and research that shaped Praxis.
They explain why current contracts exist but do not govern runtime behavior.
Load them when reviewing rationale, challenging the model, or extending a
specialized capability.

- [Industry Source Index](sources.md) classifies the primary sources.
- [Industry Research Map](landscape.md) relates the sources, failure modes, and
  Praxis responses.
- [Authorization and Access Control](security-authorization-and-access-control.md)
  preserves bounded security research used by the Security design.
