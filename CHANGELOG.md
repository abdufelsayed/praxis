# Changelog

## 2.1.0 - 2026-08-25

Praxis 2.1 tightens the optional lifecycle around fewer, deeper skills.

- Renames Ask Me to Using Praxis and Setup My Skills to Setup Praxis.
- Renames Formalize to Write Spec and makes specifications optional outputs for
  named readers rather than a mandatory lifecycle stage.
- Folds live grilling and asynchronous questionnaires into Interview.
- Folds cross-project coordination into Evolve and architecture surveys into
  Refactor.
- Removes Triage, Resolve Conflicts, and Wizard from Praxis, and removes the
  redundant flat Grill Me, Grilling, Handoff, and To Questionnaire skills.
- Keeps Orient as bounded technical comprehension, distinct from durable
  documentation and from the personal Wait What re-pitch skill.
- Keeps Using Praxis, Pair, Delegate, Plannotator, and Setup Praxis explicitly
  user-invoked while allowing Evolve and Manage Worktree to activate as bounded
  engineering methods.
- Keeps ordinary work conversational and `.praxis` persistence conditional on a
  request or named future consumer, organized by neutral efforts rather than
  lifecycle records.
- Removes durable domain-document setup, automatic review learning, cached
  tracker commands, and compulsory Plannotator review behavior.

## 2.0.0 - 2026-08-25

Praxis 2.0 replaces the brittle control layer with a compact, optional skill
lifecycle.

- Removes maintainer `SPEC.md` mirrors, control-protocol schemas, mandatory
  record reconciliation, and always-loaded governance references.
- Keeps `.praxis/` for durable cross-session artifacts only when requested or
  required by a named consumer.
- Makes Plannotator an optional native review surface rather than a compulsory
  gate.
- Preserves Praxis's discovery, design, issue, planning, delivery, pairing,
  worktree, review, security, commit, and pull-request methods in smaller skill
  bodies.
- Incorporates vertical tracer bullets, deep-module design, tight debugging
  loops, red-green TDD, two-axis code review, decision frontiers, and fog-of-war
  mapping.
- Adds Ask Me, Setup My Skills, Domain Modeling, Triage, Improve Architecture,
  Resolve Conflicts, and Wizard.
- Enables automatic selection for bounded model-invoked techniques while keeping
  explicitly collaborative entry points user-invoked.

## 1.1.0 - 2026-08-09

Original human-steered Praxis release with project records, Plannotator gates,
and the shared control protocol.
