# Changelog

## 2.0.0 - 2026-08-25

Praxis 2.0 replaces the brittle control layer with a compact, optional skill
lifecycle.

- Removes maintainer `SPEC.md` mirrors, control-protocol schemas, mandatory
  record reconciliation, and always-loaded governance references.
- Keeps `.praxis/` for durable cross-session artifacts only when requested or
  required by a named consumer.
- Makes Plannotator an optional native review surface rather than a compulsory
  gate.
- Preserves Praxis's discovery, design, issue, planning, delivery, pairing,
  worktree, review, security, commit, and pull-request methods in smaller skill
  bodies.
- Incorporates vertical tracer bullets, deep-module design, tight debugging
  loops, red-green TDD, two-axis code review, decision frontiers, and fog-of-war
  mapping.
- Adds Ask Me, Setup My Skills, Domain Modeling, Triage, Improve Architecture,
  Resolve Conflicts, and Wizard.
- Enables automatic selection for bounded model-invoked techniques while keeping
  explicitly collaborative entry points user-invoked.

## 1.1.0 - 2026-08-09

Original human-steered Praxis release with project records, Plannotator gates,
and the shared control protocol.
