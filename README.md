# Praxis

Praxis is an adaptive engineering operating system for coding agents. It bootstraps software work, chooses the lightest safe lane, routes to the right driver, and coordinates discussion, conventions, artifacts, documentation, agent guidance, lifecycle state, context persistence, worktree isolation, planning, execution, review, verification, and delivery.

The main entry point is `praxis:using-praxis`. It loads `praxis:workflow` after bootstrap.
