# Decision Template

Use when a choice should bind future work. Keep alternatives only when they prevent likely confusion. Omit empty sections.

```markdown
# <Decision Title>

Date: <YYYY-MM-DD>
Status: proposed | accepted | superseded

## Decision

<The choice in one or two sentences.>

## Context

- <constraint, prior fact, requirement, or user preference>

## Rationale

- <why this choice fits the current system>

## Consequences

- <what future agents should do differently because of this>

## Important Alternatives

- <alternative>: <why not now>

## Links

- <related context/spec/issue/plan/evidence/source>
```
