# Compatibility evidence

Use this branch when a claim spans browsers, platforms, runtimes, dependency
versions, configurations, protocols, or compatibility states.

Derive the promised matrix and material dimensions from the governing claim.
Choose the smallest cells capable of exposing divergent behavior; shared paths,
standards, engines, images, fakes, or compatibility layers justify equivalence
only when the claimed behavior does not cross a divergent branch.

Exercise the behavior where compatibility matters, including failure,
fallback, negotiation, upgrade, downgrade, and mixed-state paths when
promised. Record target, environment, versions, configuration, dependencies,
and observation per cell. An unavailable environment is `unverified`; an
emulation or shim states its supported scope.

Return the matrix, tested cells, equivalence, correlations, gaps, and status to
the loading procedure. This reference owns no route, authority, completion
claim, or stop.
