# Distill

Write the operational truth, not the archaeology.

## Required Reads

Choose the target artifact first. Read `../workflow/references/artifacts.md` only when the artifact type is unclear.

Then use the target owner:

- `exploration`: use `../workflow/references/templates/exploration.md`;
- `evidence`: use `praxis:review`, `praxis:verify`, or `../workflow/references/templates/evidence.md`;
- other artifacts: load the target artifact skill for its contract.

## Rules

- Preserve current intent.
- Preserve decisions and live constraints.
- Preserve open questions and blockers.
- Drop discarded options unless future agents are likely to repeat them.
- Do not write self-referential process commentary.
- Do not frame artifacts around what was ignored.

## Next Skills

Load the target artifact skill or template before writing the final artifact.
