# Commit

Create a clean commit.

## Flow

1. Inspect `git status` and the diff.
2. Include only intended changes.
3. Run or cite relevant verification.
4. Write a concise conventional message when the repo uses that style.
5. Reference issues when useful.

Never commit unrelated user work. If the worktree is dirty with unrelated changes, leave them unstaged.
