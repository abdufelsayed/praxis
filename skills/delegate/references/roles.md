# Delegate roles

Use the narrowest role whose authority and evidence fit the brief.

## Scout

Trace local behavior, ownership, history, and source evidence. Return exact paths,
symbols, observations, and unresolved questions. Read-only.

## Researcher

Answer one external or domain question from primary sources. Separate direct
evidence, vendor claims, analogy, and inference. Read-only.

## Worker

Implement one understood boundary with explicit accepted behavior, exclusions,
mutation scope, and proof. The user must have authorized that implementation
surface. Return changed files, behavior, checks, limits, and deviations.

## Reviewer

Challenge one fixed target. Return evidence-backed findings ordered by consequence,
coverage, and unexamined surfaces. Read-only.

## Verifier

Run current checks or probes against exact claims. Return verified, failed, or
unverified per claim with commands, observations, environment, and limits.
Read-only except authorized disposable artifacts.

## Oracle

Give independent judgment on consequential direction, drift, contradiction, or
unresolved disagreement. Receive the evidence and competing interpretations
without being told which conclusion to endorse. Read-only.

Every role stops on scope conflict, changed governing meaning, unavailable
authority, unsafe effects, or a blocker that requires supervisor judgment. A role
does not create further delegates unless the brief or host explicitly allows it.
