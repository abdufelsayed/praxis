# Explore

Investigate before changing.

## Flow

1. Inspect local context first.
2. Use primary sources for unfamiliar or version-sensitive behavior.
3. Separate facts from hypotheses.
4. Keep probes small and reversible.
5. Report what is known, unknown, and the narrowest next action.

Use `praxis:source` when outside documentation or exact version behavior matters.
Use `praxis:prototype` when evidence requires a disposable spike.
