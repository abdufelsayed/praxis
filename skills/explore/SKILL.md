# Explore

Investigate before changing.

## Required Reads

Load `praxis:source` when outside documentation, exact version behavior, security, law, finance, medicine, or fast-changing facts matter.

## Flow

1. Inspect local context first.
2. Use primary sources for unfamiliar or version-sensitive behavior.
3. Separate facts from hypotheses.
4. Keep probes small and reversible.
5. Report what is known, unknown, and the narrowest next action.

## Next Skills

Load `praxis:prototype` when evidence requires a disposable spike. Load `praxis:distill` before preserving findings as an exploration artifact. Load `praxis:decide`, `praxis:spec`, or `praxis:plan` when exploration creates durable direction.
